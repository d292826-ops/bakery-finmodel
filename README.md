# Финансовая модель пекарни

Статический сайт: `dist/index.html`, `dist/styles.css`, `dist/model.mjs`, `dist/app.mjs`; анализ чувствительности — `dist/sensitivity-model.mjs` и `dist/sensitivity.mjs`.
Исходная таблица сохранена без изменений. Для обновления источника требуется явная правка модели, сайт не подключён к Google Sheets.

## Согласованный объём

- Девять карточек, четыре диаграммы, изменяемые параметры справа.
- Все строки ОПиУ (24–45) и ДДС (50–63) исходного листа «Финмодель».
- Три сценария с пятью дельтами. Общий расчёт для сценариев, карточек и отчётов.
- Исправлены ссылки, календарь и диапазоны горизонта 1–24 месяца.
- Все начальные сценарные дельты равны нулю. Активный сценарий применяется к обзору и отчётам.
- Страница «Сценарии» (`/#scenarios`) повторяет три блока исходного листа: редактируемые базовые параметры, сценарные допущения и расчёт по сценариям. У каждого изменяемого поля указаны единицы. Базовые поля синхронизированы с «Обзором».
- По запросу пользователя базовый трафик повышен до 15000 посетителей/месяц при конверсии 25% и чеке 250 ₽. Другие входы и формулы сохранены. Окупаемость 5 месяцев (в пределах 24), месячная выручка 937500 ₽, чистая прибыль 6743,55 ₽. Исходный набор с трафиком 500 сохранён отдельно как SOURCE_DEFAULTS для регрессионной сверки.
- Страница «Чувствительность» (`/#sensitivity`): четыре карточки месячной прибыли, 10 факторов с единицами, диаграмма влияния, график с таблицей и матрица двух факторов. Изменения относительно выбранного сценария перемножаются с его допущениями; расчёт прибыли выполняется общей функцией calculate. Эксперименты не меняют исходные параметры или сценарные дельты.
- Состояние расчётов хранится в памяти текущей страницы и не сохраняется после перезагрузки. Только признак просмотра экскурсии чувствительности хранится в sessionStorage до окончания сеанса.

## Сохранённые допущения

Трафик считается за расчётный месяц, маркетинг 0,5 руб./месяц — числовое поведение исходной формулы до уточнения единиц. Начальный трафик сайта изменён по отдельному запросу пользователя, см. выше.
Амортизация первой позиции 95000/84; инвестиции шести позиций 1061500.
ФОТ в ОПиУ 290000, в ДДС множитель 1.34.
Сырьё оплачивается по формуле raw*(1-DPO/30), дальнейшее погашение отсрочки не добавлено.
Упаковка, санитария и логистика 3%,2%,5% учитываются в ОПиУ и отдельно в ДДС не добавлены.
NPV включает первый поток в t=0. Окупаемость строго при накопленном потоке >0.
Нулевая выручка даёт неопределённые маржи (null, на экране прочерк).
Методические изменения амортизации, взносов и графика оплат не включены без отдельного согласования.

## Локальный запуск

`python3 -m http.server 8765 --bind 127.0.0.1 --directory dist`

Открыть http://127.0.0.1:8765/#sensitivity (анализ чувствительности) или http://127.0.0.1:8765/#scenarios (сценарии).

## Интерактивная аналитическая записка

Вкладка `/#memo` обновляет выводы по выбранному сценарию и месяцу. Добавлены стресс-тест посещаемости, подбор порога безубыточности и целевой прибыли, сверка прибыли с денежным потоком до CAPEX, четыре проверяемых решения, их совместный эффект с регулярным бюджетом, поясняющие диалоги, ссылки на отчёты и отмечаемый план действий. Рекомендации обусловлены цифрами текущего сценария; проценты решений — допущения для теста, не прогноз.

Подбор посещаемости использует существующую calculate с остальными сценарными значениями, диапазон 0–1000000, результат округляется вверх до целого посетителя. Бюджет внедрения прибавляется один раз к маркетингу в копии параметров; пакет действует с первого месяца на весь горизонт. Исходные параметры и дельты не меняются. Формулы ОПиУ и ДДС не изменены. Методические ограничения вынесены рядом с окупаемостью и раскрыты в подсказках, дополнительная методическая ссылка — ACCA.

`node --test model.test.mjs sensitivity.test.mjs memo.test.mjs` проверяет источник, чувствительность, минимальность подобранного трафика, границы, сверку прибыли и денег, совместный эффект и бюджет, неизменность базы. Контроль: 14761 посетитель/мес. для безубыточности; 16539 для цели 50000 ₽/мес.; трафик и чек +5% при бюджете 10000 ₽/мес. дают прибыль 39985,74 ₽.

29.09.2026 проверено в изолированном Chrome: динамические выводы, сценарий/месяц, цель, стресс, изменения решений, общий бюджет, сброс, нулевые и ошибочные входы, переход к отчётам, флажки плана, диалоги и Escape, перезагрузка, мобильная ширина 390 px. Нет ошибок JavaScript, повторяющихся ID и горизонтального переполнения страницы. Исходные расчёты сохранены.
